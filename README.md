# LuxeEstate

The application is in [Real Estate website(FULLSTACK PROJECT)](./Real%20Estate%20website(FULLSTACK%20PROJECT)/README.md).

With Node.js 22+ and MongoDB running, start from this folder:

```powershell
npm.cmd start
```

Open http://localhost:3000. First startup creates a private `.env` inside the application folder with your admin credentials. Read the application README for installation, accounts, tests, and configuration.
